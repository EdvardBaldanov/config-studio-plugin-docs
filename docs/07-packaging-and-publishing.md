# Упаковка, Публикация и Каталог 📦

Когда ваш плагин готов, вы можете распространять его среди пользователей или предложить в официальный каталог Config Studio.

---

## 1. Подготовка репозитория на GitHub

Создайте отдельный публичный репозиторий на GitHub (например, `https://github.com/username/config-studio-my-plugin`).

В корне репозитория должны находиться:
```
config-studio-my-plugin/
├── .gitignore
├── README.md         # Описание, скриншоты, инструкции по установке
├── plugin.json       # Обязательный манифест
├── main.js           # Точка входа JavaScript
└── style.css         # Стили (если используются)
```

### Как работает установка по URL:
Когда пользователь указывает ссылку на ваш репозиторий в окне установки:
```
https://github.com/username/config-studio-my-plugin
```
Сервер Config Studio автоматически:
1. Загружает архив `main.zip` с GitHub Releases/ветки.
2. Проверяет пути на отсутствие уязвимости Zip-Slip.
3. Находит `plugin.json` и считывает `id`.
4. Распаковывает плагин в `data/plugins/<id>/`.
5. Мгновенно регистрирует и активирует плагин в памяти браузера без перезагрузки сервера!

---

## 2. Создание ZIP-архива для оффлайн-установки

Если плагин распространяется в закрытой сети или локально:
1. Выделите файлы плагина: `plugin.json`, `main.js`, `style.css` (и вложенные ассеты, если есть).
2. Создайте обычный zip-архив:
   ```bash
   zip -r my-plugin.zip plugin.json main.js style.css
   ```
3. Пользователь сможет установить его простым перетаскиванием (drag-and-drop) в окне «Настройки» → «Плагины».

---

## 3. Добавление плагина в Официальный Каталог Config Studio

Каталог официальных плагинов позволяет пользователям устанавливать ваш модуль в **1 клик**.

### Критерии включения:
1. **Качество кода**: отсутствие утечек памяти, обработка ошибок, корректная очистка слушателей при перерендере.
2. **Безопасность**: соответствие манифеста запрашиваемым привилегиям, отсутствие обфусцированного кода.
3. **Документация**: понятный README с описанием, списком горячих клавиш и скриншотами.

### Как подать заявку:
1. Опубликуйте рабочий репозиторий с версией `1.0.0`.
2. Создайте Pull Request в основной репозиторий [EdvardBaldanov/Config-Editor](https://github.com/EdvardBaldanov/Config-Editor) с добавлением объекта в константу `OFFICIAL_CATALOG` в файле [`SettingsModal.tsx`](web/src/components/SettingsModal.tsx):

```typescript
{
  id: 'my-plugin',
  name: 'Название плагина',
  version: '1.0.0',
  description: 'Краткое описание возможностей',
  icon: 'cpu', // Имя Lucide иконки или эмодзи
  repoUrl: 'https://github.com/username/config-studio-my-plugin',
  tags: ['Инструменты', 'DevTools']
}
```
3. После слияния PR ваш плагин появится в каталоге у всех пользователей Config Studio!
