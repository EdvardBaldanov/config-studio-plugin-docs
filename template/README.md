# My Awesome Plugin for Config Studio 🚀

A plugin starter template for [Config Studio / Config Editor](https://github.com/EdvardBaldanov/config-studio).

## Features
- Toolbar button with interactive notifications.
- Custom split-screen panel.
- Clean CSS styling.

## Installation
In Config Studio:
1. Open **Settings (⚙️) → Plugins**.
2. Enter the repository URL: `https://github.com/your-username/my-awesome-plugin`.
3. Click **Install**.
